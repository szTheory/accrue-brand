# Accrue imagery

## The photo grade

- **White balance:** neutral to a touch warm, so whites sit near Ledger Paper, never blue.
- **Contrast:** gentle. Bright areas stay soft and dark areas never go fully black, so no detail is lost.
- **Saturation:** well below the camera’s, so Ledger Green stays the strongest color on the page.
- **Shadows:** a faint green tint toward Ledger Green; bright areas stay neutral.

No heavy filters, vignettes, fake grain or sepia, and never a teal-and-orange grade. The set should look like it was shot on one quiet afternoon.

`accrue-ledger-daylight.cube`: A LUT (color lookup table) is a small file that applies one color grade to any photograph. Apply `accrue-ledger-daylight.cube` in Lightroom or Photoshop (Color Lookup), Resolve, Final Cut, Premiere or ffmpeg (`lut3d`), at 100% on a correctly exposed photograph; lower the opacity if a photo was already muted. Input and output are sRGB-encoded values.
